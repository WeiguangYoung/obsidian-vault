# 🚗 吉利汽车 — DevOps工程师

## 📍 基本信息
| 项目 | 内容 |
|------|------|
| **公司** | 吉利汽车 |
| **职位** | DevOps工程师 |

## 📋 职位详情

**岗位定位：** 面向汽车软件研发体系的 DevOps 工程师，涵盖传统 CI/CD 流水线建设、云原生容器化交付、嵌入式 C++ 交叉编译、多技术栈构建管理，并引入 AI 赋能 DevOps（AIOps）方向。

### 岗位职责

**流水线建设**
- 基于 Jenkins Pipeline 搭建分级 CI/CD 流水线，搭建每日构建体系
- 排查编译、构建、版本故障，封装可复用流水线公共库

**代码管理与质量门禁**
- 维护 Git/Repo、Gerrit/GitLab 代码基线与分支管理
- 集成 SonarQube、Coverity 等代码质量扫描工具，完成工具链优化

**自动化开发**
- 使用 Shell/Python/Go/Groovy 等语言开发自动化脚本与内部效能工具
- 输出研发操作文档，指导研发本地开发调试

**云原生交付**
- 落地 Docker、K8s 云原生环境，基于 KubeSphere 优化容器化交付流程

**多技术栈构建**
- 支撑嵌入式 C++ 交叉编译、Java/Go/Python 微服务多技术栈项目构建与依赖管理

**技术调研**
- 调研前沿技术，负责研发工具选型、研发流程梳理与效能优化落地
- 协同团队解决跨环境复杂构建问题

**AI 赋能 DevOps（亮点）**
- 建设 AI 赋能的 DevOps 体系
- 落地 AI 辅助代码评审、智能构建故障诊断、流水线智能优化等能力
- 推动大模型在研发效能（AIOps）场景的工程化应用

### 任职要求

**学历与基础**
- 本科及以上学历，计算机科学与技术、软件工程、电子工程等相关专业
- 扎实的计算机科学基础：操作系统原理、计算机网络、数据库、分布式系统与云原生概念

**编程能力**
- 熟悉 Python、Shell、Go、Java、Groovy 等编程语言
- 能够编写高质量自动化脚本和工具

**CI/CD 核心**
- 精通 Jenkinsfile 及其声明式与脚本式语法
- 具备设计和实现复杂、可复用可优化流水线库的能力

**工具链**
- 精通 Git/Repo、GitLab/Gerrit 代码评审
- Jenkins、SonarQube/Coverity 代码质量与安全扫描工具的集成与优化

**云原生**
- 熟悉 Docker 容器化技术、Kubernetes 集群编排与管理
- 有 KubeSphere 等平台的实践经验者优先

**构建与依赖管理**
- 熟悉嵌入式 C++ 项目的编译构建与交叉工具链配置
- 熟悉 Java(Maven/Gradle)、Python、Go 等语言的构建与依赖管理

**软技能**
- 优秀的编译问题解决能力，能快速定位和解决跨平台、跨环境的依赖、链接及构建失败等复杂问题
- 良好的沟通协作能力和团队合作精神
- 对技术有强烈的进取心

## 🦐 虾管家点评
> 吉利方向 = 传统 CI/CD + 云原生 K8s + 嵌入式构建 + **AI DevOps**。亮点是第 7 条引入 AI 赋能 DevOps（AI 代码评审、智能故障诊断、AIOps），相比奇瑞/比亚迪/智元的 JD 多了 AI 方向的前瞻性要求。KubeSphere 是加分项，嵌入式 C++ 交叉编译是硬骨头。
