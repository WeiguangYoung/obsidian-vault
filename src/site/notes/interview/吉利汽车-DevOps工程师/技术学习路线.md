# 🚗 吉利汽车 DevOps工程师 — 技术学习路线

## 1. Jenkins Pipeline 深度（核心）

- Pipeline as Code：声明式 vs 脚本式语法
- Shared Library 共享库设计与封装
- 多分支流水线（Multibranch Pipeline）
- 参数化构建、并发构建控制
- Jenkins Agent 节点管理（静态/动态/Docker Agent）
- 每日构建体系设计：Nightly Build → 报告 → 通知
- Jenkins 与 Gerrit 集成（Gerrit Trigger 插件）

## 2. Git/Repo + Gerrit 代码管理 🆕

- Repo 多仓库管理：manifest 编写、repo sync/start/upload
- Gerrit 工作流：Commit → Review → +1/+2 → Submit
- Gerrit + Jenkins CI 验证联动
- GitLab MR 流程与分支策略（Trunk-Based / Git Flow）
- 代码基线管理：Release Branch → Hotfix → Tag

## 3. 代码质量门禁

- SonarQube 质量门：Quality Gate 配置、自定义规则
- Coverity 静态分析：精度高于 SonarQube 的商业工具
- Cppcheck 开源静态分析
- 门禁流水线设计：Check → Block MR / 告警

## 4. 脚本与工具开发

- Shell：自动化构建脚本、日志分析、环境配置
- Python：CI/CD 工具开发、Jenkins API 封装、数据处理
- Go：K8s Operator、高性能 CLI 工具
- Groovy：Jenkins Shared Pipeline Library

## 5. 容器与 K8s + KubeSphere 🆕

- Docker 多阶段构建、构建节点镜像封装
- K8s 核心资源：Pod / Deployment / Service / Ingress / ConfigMap / PVC
- KubeSphere 专项：
  - 企业空间与多租户体系
  - 可视化流水线编排
  - 灰度发布（蓝绿/金丝雀）
  - 内置可观测性（Prometheus + Grafana + EFK）

## 6. 多技术栈构建 🆕

### 嵌入式 C++ 交叉编译
- CMake 构建系统：toolchain file、交叉编译配置
- Conan / vcpkg：现代 C++ 依赖管理
- arm-none-eabi-gcc / aarch64-linux-gnu 工具链
- 构建产物：.elf → .bin/.hex，objcopy/size 工具链

### Java 微服务
- Maven：pom.xml、多模块聚合、生命周期
- Gradle：build.gradle、增量构建、Wrapper
- Spring Boot 项目 CI/CD 实践

### Go
- go mod 依赖管理
- 交叉编译（GOOS/GOARCH）
- 静态编译与最小镜像

### Python
- pip/poetry 依赖管理
- pytest 单元测试
- 多版本管理（pyenv）

## 7. 研发效能度量 🆕

- DORA 四大指标：DF / LT / CFR / MTTR
- 指标采集方案：GitLab API → Jenkins API → K8s API → 看板
- 价值流映射（VSM）
- 效能改进案例

## 8. 🔥 AI 赋能 DevOps / AIOps（吉利亮点）🆕

这是吉利 JD 相比其他岗位最大差异点，需重点准备。

### AI 代码评审
- LLM 驱动的 MR/PR 自动审查
- CodeRabbit / Copilot Code Review 实践
- 自研方案：LLM API + GitLab Webhook + 定制 Prompt

### 智能构建故障诊断
- 构建日志 → LLM 智能分类（编译/链接/依赖/环境）
- 根因分析（RCA）：多轮对话式排查
- 修复建议生成 + 历史故障匹配（RAG）

### 流水线智能优化
- 测试影响分析（TIA）：只跑受影响的测试
- 构建缓存策略、并行度优化
- 资源动态调度

### 大模型工程化
- API 调用 vs 私有化部署（vLLM / Ollama）
- RAG 检索增强生成（向量数据库 + 技术文档）
- 数据安全：代码不出域、审计日志

### 面试准备
- STORY：「我做过的 AI DevOps 实践」
  1. 场景：CI 构建失败率高，平均 MTTR 4h+
  2. 方案：构建日志 → LLM 诊断 → 自动分类 + 根因分析
  3. 效果：MTTR 降到 1.5h，减少 60% 排查时间
  4. 技术：Jenkins Pipeline 集成 LLM API，日志分块 + Prompt 工程

## 9. 分布式系统与计算机基础

- 操作系统：进程/线程、内存管理、文件系统、IO 模型
- 计算机网络：TCP/IP、HTTP/2、gRPC、负载均衡
- 数据库：SQL（PostgreSQL/MySQL）、NoSQL（Redis/MongoDB）
- 分布式：CAP 理论、一致性协议、服务发现、分布式锁
