# 高性价比人生指南（HowToLiveBetter）

> **一句话**：把人生决策当工程问题处理——用最少的钱、时间和精力，换回寿命、金钱和自由。
>
> 这不是鸡汤，而是一本**可查、可核对、可量化**的参考手册。每条建议都写明：花掉什么（钱 / 时间 / 毅力）→ 换回什么 → 证据有多硬 → 原始出处。

## 核心理念

1. **成本-收益量化**：每条写清「花多少钱 / 时间 / 毅力 → 换回什么」。
2. **证据分级**：分 A / B / C 三级，A 级有荟萃分析、大型试验支撑。
3. **来源硬核**：只引**期刊论文**和**官方文件**，附链接可核对；核实过程记录在仓库 `docs/核实记录`。
4. **说人话**：把统计数字翻译成日常语言。
5. **非任务清单**：作者明说——这是按性价比排好的**备选单**，不是任务清单，挑走一两条就算数，作者自己也没做到大部分。

**健康与长寿**

1. 不要早死 —— 几乎不花钱就能明显降低早死概率的事
2. 不要慢慢死 —— 抽烟、喝酒、久坐、熬夜折寿多少，烟酒怎么戒，家常油怎么选
3. 不要浪费精力 —— 精力不够用、总被打断怎么改
4. 不要浪费时间 —— 时间花哪去了，拖延怎么治

## 进阶用法

- **在线检索页**：仓库根目录 `index.html`，可按关键词、章节、证据等级、成本维度（花钱 / 花时间 / 要毅力）筛选条目。开启 GitHub Pages 后即可访问。
- **电子书**：`tools/epub/` 提供 EPUB 生成脚本（`cd tools/epub && npm ci && npm run build`，产物在 `dist/`）；GitHub Actions 在正文改动后自动构建并更新 Release。
- **AI 技能插件**：仓库提供 skill，支持 Claude Code 和 Codex。装上后直接问「替朋友担保签不签」，它会先查书里的条目再回答，并注明出自第几节第几条。
- **单文件离线版**：https://cdyforever.github.io/how-to-live-better/（零外部资源、断网可读、支持搜索）
- **阶段化行动手册**：https://how2livebetter.net（按高中 / 大学 / 刚工作 / 中年 / 退休重组）
- **Android APP**：https://github.com/llzx373/BetterLifeApp
