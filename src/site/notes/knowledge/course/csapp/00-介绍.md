## 二、课程概况

| 项 | 内容 |
|:--|:--|
| 开课院校 | CMU |
| 先修 | CS61A + CS61B |
| 编程语言 | C |
| 难度 | 🌟🌟🌟🌟🌟 |
| 预计投入 | 150 小时 |

**课程主线**：汇编语言 → 数据表示 → 体系结构 → 操作系统 → 编译链接 → 并行与网络。作为系统入门课，兼具深度和广度，内容庞杂、Project 难度高，自学需要相当的毅力和代码功底。

北大购买了这门课的版权并开设了 *Introduction to Computer System*（ICS），所有课程资源和实验代码在官方主页可直接访问。

> ⚠️ 这门课过于出名，Project 答案在网上几乎唾手可得。**如果真的想锻炼代码能力，请不要借鉴任何第三方代码。**

## 七、学习路径定位

```
15-213（CSAPP）→ CS61C → xv6（6.S081）→ 18-447（按需）→ 15-418（后阶选学）
```

- 本课是整体课程学习路线（CSAPP → CS61C → xv6）的**第 1 阶段**主干，先于 CS61C。
- 建议教材认真通读，Lab 尽量都做（产出是代码，不是笔记）；嵌入式视角可跳 Proxy、Malloc 选做。
- 《程序员的自我修养》放在读完后作为第 7 章补充，不建议抢先读。
