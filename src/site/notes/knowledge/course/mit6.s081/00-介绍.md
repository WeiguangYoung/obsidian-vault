## 一、课程概况

| 项 | 内容 |
|:--|:--|
| 开课院校 | MIT PDOS（Parallel and Distributed Operating Systems 组） |
| 课程号 | 6.S081（2020 版），现更名 6.1810 |
| 教材 | xv6 教学操作系统（RISC-V 版） |
| 目标架构 | RISC-V（rv64） |
| 运行环境 | QEMU 模拟 |
| 核心产出 | 在一个约 9000 行的真实内核上完成 8 个 Lab |

**课程主线**：以一个完整可运行的教学内核 xv6 为样本，把「操作系统如何在硬件之上提供抽象」这件事拆到代码级——进程与地址空间、trap 与系统调用、页表与缺页、中断与设备驱动、锁与调度、文件系统与崩溃恢复。

与纯理论的操作系统课不同，6.S081 的每个概念都能对应到 `kernel/` 下的具体文件，并且必须自己动手改代码才能通过 Lab。

## 五、笔记覆盖范围

本文件夹的课程笔记覆盖 **L2 – L11**，即从「操作系统组织」到「崩溃恢复」的主干部分：

```
02  OS Organization and System Calls   进程抽象 / 隔离 / 内核组织 / 启动
03  Page Tables                        分页硬件 / 三级页表 / 内核地址空间
04  Traps                              用户态陷阱 / trampoline / trapframe
05  Page Faults                        惰性分配 / COW / 缺页处理
06  Interrupts                         设备驱动 / PLIC / 控制台读写
07  Locks                              自旋锁 / sleep lock / 锁序
08  Threads                            上下文切换 / 调度器 / 多核
09  Sleep & Wakeup                     sleep/wakeup / 管道 / exit/wait
10  File System                        七层结构 / inode / 目录 / 路径
11  Crash Recovery                     日志 / 崩溃恢复 / 原子性
```

**未覆盖**：L1（导论）、L12 之后的网络、mmap、虚拟化等专题，以及全部 Lab。

## 七、说明

- 笔记正文按课堂讲授顺序整理，术语保留英文原词（如 `trapframe`、`PTE_V`、`sbi`），便于与源码、讲义对照。
- 原文中的截图已全部改写为文字、表格或 mermaid 图，便于纯文本阅读与检索。
- 结构说明、寄存器值、磁盘布局等关键内容以表格 / 代码块形式保留，不依赖图片。
