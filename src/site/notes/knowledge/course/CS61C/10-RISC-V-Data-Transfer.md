## 一、目前学了什么

```asm
add   rd rs1 rs2     R[rd] = R[rs1] + R[rs2]
addi  rd rs1 imm     R[rd] = R[rs1] + imm
sub   rd rs1 rs2     R[rd] = R[rs1] - R[rs2]
```

> **RV32I**：RISC-V ISA 变体——**32 位、整数指令**。
> 寄存器：`x0` 到 `x31`；立即数：嵌入指令里的常量。

**Verilog 记法**：`R[rs1]` 表示「寄存器 rs1 里的数据」。

## 二、x0 与伪指令

### 2.1 x0 的两种用法

```asm
add  x3, x4, x0     # f = g        （+0 不影响）
addi x3, x0, 10     # f = 10       （从 0 加）
add  x0, x3, x4     # no-op        （写入 x0 无效）
```

> **x0 在硬件中定义为 0。** 写入它什么都不发生——这对**伪指令**很有用。

### 2.2 伪指令（Pseudoinstruction）

> **伪指令是 RISC-V 里「方便的指令」。**
> 它**不是「真」指令**，因为可以用已有指令实现同样的效果。
> **汇编器会把它替换成真正的指令。**

**例子：`li`（Load Immediate）**

```asm
li rd, imm        # R[rd] = imm
```

**翻译成真指令：**

```asm
li  x1, 5    →    addi x1, x0, 5
```

> **`li` 之所以能实现，正是因为 x0 恒为 0。**

## 三、为什么需要内存

### 3.1 速度与容量的权衡

| 层级 | 速度 | 容量 |
|---|---|---|
| **寄存器** | **~0.1 ns** | **32 × 4 B = 128 B** |
| **主存（主存）** | **比寄存器慢 50–500 倍** | **笔记本 2–64 GB** |

> **寄存器快但极少；内存慢但极大。**
> **这正是 Great Idea #3：Memory Hierarchy。**

### 3.2 32 位系统的内存

> **现代机器是 byte-addressable（按字节编址）。**

```
32 位系统：
  2³² 个可寻址内存字节
  每个字节一个 32 位地址
  1 word = 4 字节
```

```
      +3   +2   +1   +0
0x100 0xB0 0xBA 0xCA 0xFE
0x104 0x44 0x33 0x22 0x11
0x108 0x00 0x00 0x00 0x14
```

> ⚠️ **RISC-V 是 little endian（小端）**：
> **字被切成 4 字节，最低有效字节存在最低地址。**

## 四、Load / Store 指令

### 4.1 核心思想

> **RISC-V 在内存和寄存器之间移动数据的指令：**
> - 要对数据做运算，**先把数据从内存 load 到寄存器**
> - 寄存器空间不够时，**把数据 store 回内存**

```
       load
内存 ─────────→ 寄存器
     ←─────────
       store
```

### 4.2 `lw`：Load Word（读 4 字节）

```
语法：lw rd imm(rs1)
语义：R[rd] = M[R[rs1] + imm]
```

**含义：**

1. **计算地址**：`R[rs1] + imm`
2. **从该地址读 4 字节**到 `R[rd]`

**术语：**

| 术语 | 说明 |
|---|---|
| **Base register（基址寄存器）** | `rs1` |
| **Offset（偏移）** | `imm`，**必须在汇编时已知的常量** |

**例子：**

```asm
lw x10, 0(x5)     # 从地址 R[x5] 读一个字到 x10
lw x11, 4(x5)     # 从 R[x5]+4 读
```

### 4.3 `sw`：Store Word（写 4 字节）

```
语法：sw rs2 imm(rs1)
语义：M[R[rs1] + imm] = R[rs2]
```

**含义：**

1. **计算地址**：`R[rs1] + imm`
2. **把 `R[rs2]` 的 4 字节**写到该地址

**术语：**

| 术语 | 说明 |
|---|---|
| **Base register** | `rs1` |
| **Offset** | `imm` |
| **⚠️ Word alignment** | `R[rs1] + imm` **必须是 4 的倍数** |

> **注意 `sw` 的参数顺序是 `rs2, imm(rs1)`** ——
> **要存的数据在前，地址在后**（和 `lw` 不同）。

### 4.4 记忆诀窍

```
lw   rd,  imm(rs1)     ← 读：目的地在前
sw   rs2, imm(rs1)     ← 写：数据在前
```

## 五、字节级传送

### 5.1 为什么需要

> **除了字传送（`lw`/`sw`），RISC-V 还支持字节级传送：**

```asm
lb  rd, imm(rs1)      # load byte
sb  rs2, imm(rs1)     # store byte
```

**问题**：寄存器是 4 字节（word），**怎么只 load/store 1 字节？**

> **由 RISC-V 规范定义！**

### 5.2 `sb`：Store Byte

> **对 `sb`，我们存的是最低有效字节（LSB）。**

```asm
sb x10, 0(x5)    # x10 = 0x123456EF，x5 = 0x100
```

**结果（内存 0x100 处）：**

```
      +3   +2   +1   +0
0x100 0xB0 0xBA 0xCA 0xEF    ← 只有最低字节被改了
```

> **只写 1 个字节，其余 3 个字节原封不动。**

### 5.3 `lb` 的两种：符号扩展 vs 零扩展

> **`lb` 把 1 字节读进寄存器。**
> **问题：8 位整数要扩展成 32 位整数。怎么扩？**
> **答案：取决于你的整数表示方式。**

| 指令 | 名称 | 扩展方式 |
|---|---|---|
| **`lb`** | load byte，**sign-extend** | 用**最高位（符号位）**填满高 24 位 |
| **`lbu`** | load byte unsigned，**zero-extend** | 用 **0** 填满高 24 位 |

**例子：读 1 字节 `0xEF`**

**`lb`（有符号）：**

```
0xEF = 0b1110 1111
最高位是 1 → 高 24 位填 1
→ 0xFFFF FFEF = -17 (十进制)
```

**`lbu`（无符号）：**

```
0xEF = 0b1110 1111
高 24 位填 0
→ 0x0000 00EF = 239 (十进制)
```

> **同一个字节，两条指令得到完全不同的数字！**

### 5.4 Load 指令总表

| 指令 | 全称 | 加载大小 | 填充方式 |
|---|---|---|---|
| **`lw`** | load word | **4 字节** | 无需扩展 |
| **`lh`** | load halfword | **2 字节** | sign-extend |
| **`lhu`** | load halfword unsigned | 2 字节 | zero-extend |
| **`lb`** | load byte | **1 字节** | sign-extend |
| **`lbu`** | load byte unsigned | 1 字节 | zero-extend |

> ⚠️ **没有 `lwu`！**
> **Why? 简单性——32 位读到 32 位寄存器里，没什么可扩展的。**

## 六、短例题：`lb` 的实际行为

### 6.1 题目

```asm
li  x11, 0x93F5
sw  x11, 0(x5)
lb  x12, 1(x5)
```

**已知**：`x5 = 0x0000 0100`，`x12` 原值 `0xCDEF ABCD`（垃圾）

**问：`x12` 最终是什么？**

### 6.2 逐步解答

**第 1 步：`li x11, 0x93F5`**

```asm
→ addi x11, x0, 0x93F5
x11 = 0x0000 93F5
```

**第 2 步：`sw x11, 0(x5)`**

地址 = `0x100 + 0 = 0x100`

**小端存储** `0x0000 93F5`：

```
      +3   +2   +1   +0
0x100 0x00 0x00 0x93 0xF5
```

> **注意：LSB（0xF5）存在最低地址 0x100。**

**第 3 步：`lb x12, 1(x5)`**

地址 = `0x100 + 1 = 0x101`

读 1 字节 = **`0x93`**

**符号扩展**：`0x93 = 0b1001 0011`，最高位是 **1**，所以高 24 位填 1：

```
0b1…1 1001 0011  →  0xFFFF FF93
```

**最终结果：**

```
x12 = 0xFFFF FF93      ✅
```

### 6.3 关键点复习

| 步骤 | 陷阱 |
|---|---|
| `sw` 存字 | **little endian**：LSB 在低地址 |
| `lb` 偏移 +1 | 取的是**第二个字节** |
| `lb` 符号扩展 | `0x93` 最高位是 1 → **填 1** |

## 七、长例题：栈帧与寄存器命名

### 7.1 任务

翻译这段 C 代码，**只允许修改 `x5`、`x6`、`x7`**：

```c
int a = 5;
char b[] = "string";     // 数组存在栈上
int c[10];
uint8_t d = b[3];
c[4] = a + d;
c[a] = 20;
```

**限制：**

| 约束 | 说明 |
|---|---|
| 只能改 | `x5`（t0）、`x6`（t1）、`x7`（t2），**temporary 寄存器 0-2** |
| `x2` | **sp（stack pointer）** ——「没错，就是那个 stack pointer！」 |

> **RISC-V calling convention 给寄存器起了常用名。**

### 7.2 第 1 步：分配栈帧偏移

```
a:  0(sp)      ← 4 字节
b:  4(sp)      ← 7 字节（"string\0"）
c:  12(sp)     ← 40 字节（10 × 4）
d:  52(sp)     ← 1 字节
```

> **具体地址不重要，只要保持一致。**

### 7.3 第 2 步：初始化整数 a

```c
int a = 5;
```

```asm
li t0, 5          # R[t0] = 5
sw t0, 0(sp)      # 把 int a 存到栈上
```

**内存：**

```
      +3   +2   +1   +0
0(sp) 0x00 0x00 0x00 0x05     ← a = 5
```

### 7.4 第 3 步：初始化字符串（笨办法）

```c
char b[] = "string";
```

**一字节一字节写（朴素做法）：**

```asm
li t0, 0x73      # 's'
sb t0, 4(sp)
li t0, 0x74      # 't'
sb t0, 5(sp)
li t0, 0x72      # 'r'
sb t0, 6(sp)
...
```

> **「Seems costly! Can we do better?」**（课程原话）

**ASCII 表（0x）：**

| 字符 | s | t | r | i | n | g | \0 |
|---|---|---|---|---|---|---|---|
| 十六进制 | 73 | 74 | 72 | 69 | 6E | 67 | 00 |

### 7.5 第 4 步：字符串的聪明写法

> **用 `sw` 一次写 4 字节！**

```asm
li t0, 0x69727473    # "stri"（注意 little endian）
sw t0, 4(sp)         # 存第一部分

li t1, 0x0000676E    # "ng\0"
sw t1, 8(sp)         # 存剩下部分
```

**分析 `0x69727473`：**

```
字符：s    t    r    i
ASCII：73  74  72  69
小端存储：(sp+4) 存 73
          (sp+5) 存 74
          (sp+6) 存 72
          (sp+7) 存 69
```

> **因为小端，`0x69727473` 会被存成 `73 74 72 69`** ——
> **正好是 "stri"！这就是为什么要写成这个顺序。**

**内存验证：**

```
      +3   +2   +1   +0
4(sp) 0x69 0x72 0x74 0x73     ← 'i' 'r' 't' 's'  →  正向读是 "stri"
8(sp) 0x00 0x00 0x67 0x6E     ← '\0' '\0' 'g' 'n' →  正向读是 "ng\0"
```

### 7.6 第 5 步：声明数组（零指令！）

```c
int c[10];
```

> **No data moves between registers and memory!**
> **No instructions needed — leave things as-is!**

**为什么？** 因为 `c` 的初始值不重要（马上会被赋值），**不需要初始化**。

> **这是 C「声明不等于初始化」在汇编层面的体现**（复习 L03）。

### 7.7 第 6 步：读/写字节

```c
uint8_t d = b[3];
```

```asm
lb t0, 7(sp)      # 4(sp) + 3 = 7(sp)，读 b[3]
sb t0, 52(sp)     # 存进 d
```

> **注意 `b[3]` 的地址 = `4(sp) + 3 = 7(sp)`。**

### 7.8 第 7 步：常量下标数组访问

```c
c[4] = a + d;
```

**地址计算：**

```
c 起始于 12(sp)
c[4] 的偏移 = 4 × sizeof(int) = 16
地址 = 12(sp) + 16 = 28(sp)
```

**代码：**

```asm
lw t0, 0(sp)      # t0 = a
lb t1, 52(sp)     # t1 = d
add t0, t0, t1    # t0 = a + d
sw t0, 28(sp)     # c[4] = a + d
```

### 7.9 第 8 步：变量下标数组访问（最精彩）

```c
c[a] = 20;
```

**这是个变量下标**，必须**运行时计算地址**：

```asm
li  t0, 20          # R[t0] = 20
lw  t1, 0(sp)       # R[t1] = a
slli t1, t1, 2      # 5 * sizeof(int) = 5 * 4 = 5 << 2 = 20
addi t1, t1, 12     # t1 = &c[a] 的低位部分（+12 是 c 的起始偏移）
add t1, t1, sp      # 计算 &c[a] = sp + 12 + a*4
sw  t0, 0(t1)       # c[a] = 20
```

**关键点：**

| 步骤 | 含义 |
|---|---|
| `slli t1, t1, 2` | **×4 = 左移 2 位**（比 `mul` 快，且 `mul` 不在基础 ISA 里）|
| `addi t1, t1, 12` | 加上 `c` 的起始偏移 |
| `add t1, t1, sp` | 加上 sp 得到**绝对地址** |
| `sw t0, 0(t1)` | 通过指针写入 |

> **这就是 C 里 `c[a] = 20` 在汇编层的真实展开：**
> **地址 = 基址 + 下标 × 元素大小。**

### 7.10 完整代码

```asm
# int a = 5;  →  0(sp)
li t0, 5
sw t0, 0(sp)

# char b[] = "string";  →  4(sp)
li t0, 0x69727473      # "stri"
sw t0, 4(sp)
li t1, 0x0000676E      # "ng\0"
sw t1, 8(sp)

# uint8_t d = b[3];  →  52(sp)
lb t0, 7(sp)
sb t0, 52(sp)

# c[4] = a + d;
lw t0, 0(sp)
lb t1, 52(sp)
add t0, t0, t1
sw t0, 28(sp)

# c[a] = 20;
li t0, 20
lw t1, 0(sp)
slli t1, t1, 2
addi t1, t1, 12
add t1, t1, sp
sw t0, 0(t1)
```

## 八、补充例题：`*x = *y;`

**已知**：`x`、`y` 是 `int *`，分别存在 `x3`、`x5`。

**正确翻译：**

```asm
lw x8, 0(x5)      # 读 *y 到 x8
sw x8, 0(x3)      # 写到 *x
```

**要避免的错误：**

```asm
lw x5, 0(x3)      # ❌ 覆盖了 x5（y 的指针）
sw x8, 0(x5)      # ❌ x5 已经不是 y 了
```

> **这是「临时寄存器选择」的经典考点**：
> **不要覆盖还要用的寄存器。**

## 九、本讲总结

| 类别 | 指令 |
|---|---|
| **字传送** | `lw` / `sw` |
| **字节传送** | `lb` / `lbu` / `sb` |
| **半字传送** | `lh` / `lhu` |
| **伪指令** | `li` |
| **无扩展** | 无 `lwu` |

**核心要点：**

1. **RISC-V 是 little endian**（LSB 在低地址）
2. **`sw` 有字对齐要求**（地址必须是 4 的倍数）
3. **`lb` 符号扩展，`lbu` 零扩展**
4. **变量下标访问 = 基址 + 下标 × 元素大小**

## 十、我的笔记与理解

### 10.1 本讲的核心矛盾

```
寄存器：快、少（128 字节）
内存：慢、多（GB）
```

**所有 load/store 指令，都是为了在这两者之间「搬运」。**
**这个矛盾是 Great Idea #3（Memory Hierarchy）的起点——L26 讲缓存时会有完整解法。**

### 10.2 `lb` vs `lbu` 是 L02 的现场演示

回顾 L02 的核心思想：**「同一串比特，不同解释」**。

```
0xEF 这个字节：
  lb  →  0xFFFFFFEF  =  -17
  lbu →  0x000000EF  =  239
```

> **同一个字节，两条指令的差别就是对「类型」的不同假设。**
> **这就是 L09 说的「汇编里操作决定类型」。**

### 10.3 小端字节序的实战影响

```asm
li t0, 0x69727473
sw t0, 4(sp)
```

**为什么这个数是 "stri"？**

```
0x69727473
     ↑ ↑ ↑ ↑
     6 7 1 2   →  按字节看是 69 72 74 73
                  = 'i' 'r' 't' 's'
```

**内存（小端，低地址存低字节）：**

```
4(sp) = 0x73 = 's'   ← 最低字节在最低地址
5(sp) = 0x74 = 't'
6(sp) = 0x72 = 'r'
7(sp) = 0x69 = 'i'
```

> **结果正向读是 "stri" ✅**
> **这就是为什么这个「奇怪的数字」恰好拼出正确的字符串。**

**如果换成大端机器，这段代码就会把字符串写反。**

### 10.4 指针算术的汇编展开

C 里：

```c
c[a] = 20;     // 一行
```

汇编里：

```asm
lw   t1, 0(sp)      # 读 a
slli t1, t1, 2      # ×4（元素大小）
addi t1, t1, 12     # + 数组起始偏移
add  t1, t1, sp     # + 基址
sw   t0, 0(t1)      # 写
```

> **C 的一行，汇编是五条指令。**
> **而且必须显式乘 sizeof —— 这就是 L09 判断题第 3 题的答案。**

### 10.5 `slli` 代替 `mul` 的深意

```asm
slli t1, t1, 2      # ×4
```

**为什么不用 `mul`？**

| 原因 | 说明 |
|---|---|
| **① `mul` 不在基础 ISA 里** | 属于 M 扩展（L11 会讲） |
| **② `slli` 更快** | 移位是单周期，乘法是多周期 |
| **③ 硬件更简单** | RISC 哲学 |

> **「乘 2 的幂」用移位，这是硬件优化的基本功。**

### 10.6 声明数组为什么「零指令」

```c
int c[10];       // 汇编里完全不需要指令
```

**因为**：

- 数组只是「在栈上预留 40 字节」
- **预留位置由 `sp` 偏移隐式确定**
- **初始值不重要**（马上会被赋值）

> **这和 L03「声明不等于初始化」完全一致：**
> **C 不会浪费指令去清零一个马上要覆盖的数组。**

### 10.7 与后续的衔接

| 讲次 | 关系 |
|---|---|
| **L11** | 控制流：分支、循环、`pc` |
| **L12** | 函数调用：栈帧正式登场（本讲的 `sp` 铺垫）|
| **L13-14** | 指令格式：`lw`/`sw` 的 32 位编码长什么样 |
| **L26-29** | 缓存：解决「内存慢 300 倍」的问题 |

## 十一、术语速查

| 术语 | 中文 | 说明 |
|---|---|---|
| **base register** | 基址寄存器 | `rs1` |
| **offset** | 偏移 | `imm`，汇编时常量 |
| **word alignment** | 字对齐 | 地址须为 4 的倍数 |
| **sign-extend** | 符号扩展 | 用符号位填高位 |
| **zero-extend** | 零扩展 | 用 0 填高位 |
| **pseudoinstruction** | 伪指令 | 汇编器替换成真指令 |
| **little endian** | 小端 | LSB 在低地址 |
| **sp（x2）** | 栈指针 | stack pointer |
| **t0-t6（x5-x11）** | 临时寄存器 | temporary |
| **byte-addressable** | 按字节编址 | 每字节一个地址 |
