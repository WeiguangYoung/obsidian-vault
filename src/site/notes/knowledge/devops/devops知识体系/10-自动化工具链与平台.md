# 十、自动化工具链与平台

> 覆盖自研 DevOps 平台 + 机器人工具链 + AI 辅助开发。

## 10.1 自研 DevOps 平台

### 平台架构核心

| 组件 | 职能 |
|:----|:------|
| **统一门户** | 项目管理、流水线编排、质量仪表盘、权限控制 |
| **插件化流水线** | 标准化构建/扫描/测试/部署步骤，可复用模板 |
| **多租户隔离** | 不同项目/团队的构建环境和权限隔离 |
| **Jira 集成** | 需求 → 代码 → 构建 → 测试 → 发布全链路追溯 |

### 技术栈建议

```
前端: React / Vue  →  Web UI + Dashboard
后端: Python (Flask/FastAPI) 或 Go (Gin)  →  API 服务
调度: Jenkins / GitLab CI  →  流水线引擎
存储: PostgreSQL + Redis  →  状态存储 + 缓存
制品: Harbor + Nexus  →  镜像 & 通用制品
```

### 与嵌入式构建集成

- 管理交叉编译工具链版本（不同 MCU/SoC 对应不同工具链镜像）
- 构建节点标签：`x86-linux`、`aarch64-linux`、`arm-none-eabi`
- 制品追溯：构建产物 → Git Commit → Jira Issue → 测试报告

## 10.2 机器人工具链

| 工具 | 场景 | 说明 |
|:----|:------|:------|
| **仿真平台** | 算法验证 | Isaac Sim / Gazebo / Mujoco |
| **数据处理管道** | 传感器数据清洗 | 自动化 ETL 流水线 |
| **可视化工具** | 机器人状态监控 | Rviz2 / Foxglove / 自研 Dashboard |
| **自动化测试框架** | 回归测试 | HIL 硬件在环、仿真场景批量回放 |
| **CI/CD 集成** | 机器人软件发版 | Docker 镜像构建 → 仿真测试 → 多集群灰度发布 |

### 仿真 → 真机流程

```
代码提交 → CI 编译 → 仿真测试（批量场景）
    ↓ 通过
镜像构建 → 测试集群发布 → 回归测试
    ↓ 通过
生产集群灰度 → 全量发布
```

## 10.3 AI Coding 提效

### 主流工具

| 工具 | 特点 | 适用 |
|:----|:------|:------|
| **GitHub Copilot** | IDE 内嵌，代码补全 + Chat | 日常开发 |
| **Cursor** | AI-first IDE，基于 VS Code | 复杂重构 |
| **Claude Code** | 终端 Agent，端到端开发 | 自动化任务 |
| **Codex (OpenAI)** | 多步推理代码生成 | API 集成 |

### 在 DevOps 场景的应用

| 场景 | 用法 |
|:----|:------|
| **编写流水线配置** | AI 辅助生成 .gitlab-ci.yml / Jenkins pipeline |
| **Dockerfile 优化** | 分析镜像大小、层缓存、安全建议 |
| **脚本生成** | 一键生成日志分析脚本、部署脚本 |
| **故障排查** | 贴错误日志 → AI 分析根因并给出修复建议 |
| **代码审查** | AI 自动 Review MR/PR，标记潜在问题 |

## 10.4 IaC 基础

只保留 DevOps 岗位确实需要的基础 IaC 能力：

| 工具 | 场景 |
|:----|:------|
| **Ansible** | 服务器批量配置、应用部署（SSH 无 Agent） |
| **GitOps (ArgoCD)** | 以 Git 为源驱动 K8s 部署，自动同步集群状态 |

> 注意：Terraform/Packer 在嵌入式 DevOps 场景需求极少，可不深入学习。
