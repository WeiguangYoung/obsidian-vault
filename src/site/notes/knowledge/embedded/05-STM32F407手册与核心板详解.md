## 一、什么是芯片手册

芯片手册（Chip Documentation）是**芯片厂商发布的、描述该芯片能力边界与使用方法的官方技术文档集合**。它的本质是**规格合同**：

- 手册里写的参数，厂商必须保证（在标称条件下）；
- 手册里没写的，厂商不保证，出了问题算设计方的；
- 手册里写"典型值"的地方是统计结果，**不能当设计裕量用**。

所以手册不是教程。它不教你"怎么用 CAN 做个项目"，只告诉你"CAN 控制器有 28 个寄存器，每一位是什么含义"。**教程讲意图，手册讲事实。**

STM32F407 的文档量级：

| 文档 | 大致页数 |
|:--|--:|
| 数据手册（DS8626 / DM00037051） | 200+ |
| 参考手册（RM0090） | 1700+ |
| 编程手册（PM0214） | 250+ |
| 勘误表（ES0182） | 40+ |

## 三、数据手册核心内容（DS8626）

数据手册回答"**这颗芯片在物理世界里的边界**"。

### 3.1 特性概览

- 内核：ARM Cortex-M4F，最高 **168 MHz**，单精度 FPU + DSP 指令
- 存储：**512 KB ~ 1 MB Flash**，**192 KB SRAM**（128 KB + 64 KB CCM）
- 供电：**1.8 V ~ 3.6 V**
- 封装：LQFP64 / LQFP100 / LQFP144 / BGA100 / WLCSP90
- 外设：3×12-bit ADC、2×DAC、17 定时器、3×I2C、6×USART、3×SPI、2×CAN、USB OTG FS/HS、Ethernet MAC、SDIO、FSMC

> "最高 168 MHz"有条件——通常要 VDD ≥ 2.1 V 且 Flash 等待周期配对。降压实测跑不到 168 MHz 时，先查**电压-频率对应表**，不是芯片坏了。

### 3.2 引脚定义与复用功能

数据手册翻得最多的部分，也是硬件出错的重灾区：

- **引脚分布图**：按封装给顶视图，标注 pin 1 位置
- **引脚定义表**：编号、名称、类型、复用功能、复位后默认状态、附加功能（ADC 通道、TIM 通道）
- **复用功能映射表（AF mapping）**：哪一路 USART_TX 能映射到哪几个 pin。STM32F407 的 AF 编号 0~15，例如 `PA9` 作 `USART1_TX` 是 **AF7**

查错一行，引脚就死了。

### 3.3 电气特性

| 类别 | 典型内容 |
|:--|:--|
| 绝对最大额定值 | VDD 最大 4.0 V、单引脚注入电流 ±25 mA、总注入 ±150 mA |
| 工作条件 | VDD 1.8~3.6 V；温度等级 6 = -40~85 ℃，7 = -40~105 ℃ |
| 电流消耗 | Run mA/MHz，Sleep/Stop/Standby 各模式典型值 |
| I/O 特性 | VIL/VIH、VOL/VOH、上下拉范围、引脚电容 |
| 模拟特性 | ADC 精度（INL/DNL/ENOB）、VREF 范围、DAC 建立时间 |
| 时钟特性 | HSI/HSE 精度、PLL 抖动、晶振推荐参数 |
| 时序特性 | Flash 编程时间、复位脉宽、启动时间 |

**用法**：算功耗预算、选 LDO、判断电平匹配、确定晶振负载电容，全在这一章。做低功耗产品，Stop 模式的 μA 级数字和唤醒时间必须从这里取。

### 3.4 封装、热特性、订购信息

- 封装机械图（尺寸、焊距、推荐 footprint）
- 热阻 θJA / θJC，估算结温
- **订购代码解析**：`STM32F407VGT6` = F407 + `V`(LQFP100) + `G`(1 MB Flash) + `T`(LQFP) + `6`(-40~85 ℃)

> 温度等级和封装字母是采购换料最容易搞错的地方，换料时对一遍这张表，比信供应商口头承诺可靠。

## 四、参考手册核心内容（RM0090）

参考手册回答"**这个外设的寄存器怎么配，配了会发生什么**"，是驱动开发的唯一权威依据。

### 4.1 前几章：地基

| 章 | 内容 | 为什么重要 |
|:--|:--|:--|
| 1 | 文档约定 | 读懂 `rw/r/W1C/rc_w0` 这些寄存器属性缩写 |
| 2 | 存储器与总线架构 | AHB/APB 分域、地址空间、位带 |
| 3 | 嵌入式 Flash 接口 | 等待周期 vs 主频、扇区擦除、选项字节 |

**第 2 章的存储器映射图**是排错利器：访问非法地址触发 HardFault 时，先对照看地址落在哪个区。

### 4.2 时钟与电源（第 5、6、7 章）

- **PWR**：Sleep / Stop / Standby 三种低功耗模式的进入条件、唤醒源、模式下的时钟与 SRAM 保持
- **RCC**：时钟树（HSI/HSE/PLL → SYSCLK → AHB/APB 分频）、每个外设的时钟使能位、CSS 时钟安全系统

> 新手最常见的问题"外设配好了但不动"，80% 是 RCC 里没使能该外设时钟。

### 4.3 GPIO（第 8 章）

四种输入模式（浮空/上拉/下拉/模拟）、四种输出模式（推挽/开漏 + 上下拉）、复用与模拟模式；`MODER` / `OTYPER` / `OSPEEDR` / `PUPDR` / `IDR` / `ODR` / `BSRR` / `AFR[2]` 八个寄存器。

**BSRR 的原子性**：置位/复位一次写完成，比读改写 ODR 安全（中断里也不怕）。

### 4.4 通信外设（第 24~30 章）

以 USART（第 26 章）为例，典型结构：功能框图 → 波特率计算（`USARTDIV = fCK / (16 × baud)`）→ 寄存器逐位说明 → 中断/DMA 映射 → 错误标志清除。

**状态标志清除方式是踩坑高发区**：有的读 SR 再读 DR 才清，有的写 0 清，有的写 1 清。手册每个标志后面都标了清除条件，别凭印象写。

### 4.5 定时器（第 14~17 章）

| 类型 | 实例 | 特点 |
|:--|:--|:--|
| 高级控制 | TIM1 / TIM8 | 互补输出、死区、刹车输入，给电机/电源 |
| 通用 | TIM2~5、TIM9~14 | 输入捕获、输出比较、PWM、编码器接口 |
| 基本 | TIM6 / TIM7 | 只有计数和更新事件，给 DAC 触发/时基 |

### 4.6 其它重点章

DMA（流/通道映射表、FIFO、双缓冲）｜ADC（规则/注入组、采样时间与源阻抗、多重模式）｜bxCAN（过滤器组位宽、邮箱、BTR 位定时）｜FMC（外部 SRAM/NOR/SDRAM 时序）｜ETH（DMA 描述符、MII/RMII）｜DBG（调试时冻结看门狗的 `DBGMCU`）

## 五、编程手册核心内容（PM0214）

编程手册讲 **CPU 内核**，不是 ST 的外设。ARM 也出一份架构手册，但 ST 这份更贴实际——它把内核寄存器和 STM32 的具体地址绑定了。

- **内核架构**：R0~R15、xPSR、PRIMASK/BASEPRI/FAULTMASK、CONTROL、栈对齐、特权/非特权模式
- **指令集**：Thumb-2 编码与语义、条件执行、位操作指令（`BFI`/`BFC`/`RBIT`）
- **FPU**：S0~S31、`FPCCR`/`FPSCR`、**惰性压栈**机制
- **NVIC**：优先级分组（抢占/子优先级）、`NVIC_ISER` 等地址、**优先级数值越小越高**
- **SCB 系统控制块**：`VTOR` 向量表偏移（Bootloader 必看）、`AIRCR` 软复位、`SHPRx` 异常优先级
- **MPU**：区域配置、属性、访问权限（跑 RTOS 或做安全隔离时才用）
- **异常模型**：进入/返回的压栈内容、尾链优化、延迟到达

> 写 Bootloader 跳到 App 时必须改 `SCB->VTOR`——这条在 RM0090 里找不到，只在 PM0214 里。这就是"两本手册分工"的典型例子。

## 六、勘误表与应用笔记

### 6.1 勘误表（ES0182）

列出**硅片层面已确认的缺陷**及规避方案，按模块分（内核/系统、Flash、ADC、通信外设等）。问题分两类：**有规避方法** 和 **无解（只能避免使用该功能）**。

**处理原则**：量产前必须逐条过，判断你的用法是否踩中。

### 6.2 应用笔记（AN 系列）

常用主题：时钟/晶振设计与 PCB 布局、ADC 精度提升、USB/Ethernet 硬件检查表、Flash 模拟 EEPROM、低功耗设计。

价值在于**把手册参数翻译成工程做法**，但**不具备规格约束力**——冲突时以数据手册/参考手册为准。

### 6.3 库文档（UM1725）

用 HAL 时它是 API 字典。但**HAL 只是把寄存器操作封装了一层，行为仍由 RM0090 定义**。HAL 出问题时最终还是要回参考手册看寄存器。

## 八、读手册的方法

1. **先看版本号和修订历史**。首页有 Doc ID 和 Rev，勘误表也有版本。旧版本描述的行为可能已被修订。
2. **看清限定条件**。所有参数都带前提（VDD、温度、时钟频率），脱离条件引用参数是最常见的错误。
3. **区分 typ / min / max**。设计裕量按 worst case 取，不能用 typ。
4. **看懂寄存器属性缩写**：`rw` / `r` / `w` / `rc_w0`（读清或写 0 清）/ `rc_w1`（写 1 清）/ `rs`（读置位）。搞错清除方式会导致标志永远清不掉。
5. **优先看框图再看寄存器**。功能框图告诉你数据流向和触发关系，比逐位读寄存器快得多。
6. **中文译版仅作参考**。ST 部分文档有中文版，但**更新滞后且可能翻译偏差**，关键参数以英文原版为准。
7. **手册 + 官方例程对照读**。Cube 包的 `Examples/` 是最好的"标准答案"。
8. **把勘误表加入 checklist**。不是读一遍就完，每次改硬件/改关键配置时回查。

## 九、核心板与开发板选型（一句话版）

**核心板是元器件，开发板是工具。**

- **核心板**：只留 MCU 跑起来必需的元件（MCU、晶振、复位、LDO、BOOT 选择、排针），便宜、小，适合**嵌入产品、批量、插到自研底板**
- **开发板**：核心板 + USB 转串口 + 按键 LED + 各种接口 + 四周排针，插线即用，适合**学习、验证、竞赛**
- **选型只需问一句**：我有 ST-Link 吗？没有 → 买开发板（省心）；有 → 核心板更划算（调试器是可复用资产，板子是一次性的）

芯片完全相同，差的是**调试通路和外设完整度**，不是性能。

## 十、实例：鹿小班 LXB407VG-P1 核心板

以下内容来自芯路城官方 `407VG资料包.zip` 解压后的实测整理。

### 10.1 板卡概况

| 项目 | 参数 |
|:--|:--|
| 板卡型号 | **LXB407VG-P1**（设计：鹿小班科技，图纸 V1.0 / 2024-07-15） |
| 主控 | **STM32F407VGT6**（图纸同时标注 F407VET6 兼容） |
| 封装 | LQFP100 |
| Flash / SRAM | 1024 KB / 192 KB（VG；VE 为 512 KB） |
| 主频 | 168 MHz |
| 尺寸 | **63.37 mm × 58.95 mm**，四角 R1.5 安装孔 |
| 供电 | 5V（Type-C 或外部 5V 排针）/ 也可直供 3.3V |
| 引出 | 2.54 mm 双排针 **2×21P** |

> VG 与 VE 除 Flash 容量外电气完全一致，原理图上 `U8.1 STM32F407VGT6` 与 `U8.2 STM32F407VET6` 两个符号并存，表示同一套 PCB 支持两种料号。

### 10.2 资料包结构

解压后 383 MB，6 个子目录：

| 目录 | 内容 |
|:--|:--|
| 【1】参考例程 | `HAL库/` 与 `标准库/` 两套，各 6 个工程 + CubeMX 配置 |
| 【2】工具软件 | PCtoLCD2018（取字模）、SSCOM v5.13.1 串口助手 |
| 【3】STM32相关手册 | F407 参考手册中文版（21 MB）、勘误表、IO 复用说明图 |
| 【4】原理图尺寸图 | 原理图 PDF、机械尺寸 PDF、正反面照片 |
| 【5】下载器驱动 | DAP 串口驱动、CH340 驱动 |
| 【6】供电说明 | 供电拓扑示意图 |

> 官网另给 `PCB封装立创EDA专业版.zip` 与 `鹿小班-STM32F407VET6-Mini款PCB封装.zip`（AD）。**AD 那个是 VET6-Mini 款，不是这块 VG 核心板**，画底板别直接套。

### 10.3 电源设计

```
Type-C VBUS (5V)  ─┐
                   ├─→ RY3420 (同步降压) ──→ 3.3V ──→ STM32 + 外设
外部 5V 排针      ─┘        │
                      4.7 µH 电感
                      45.3k / 10k 反馈分压
```

| 器件 | 型号/参数 | 说明 |
|:--|:--|:--|
| 降压 IC | **RY3420** | 同步降压，5V → 3.3V |
| 功率电感 | 4.7 µH | 配合 RY3420 |
| 反馈电阻 | 45.3 kΩ / 10 kΩ | 决定输出 3.3V |
| 输入滤波 | 10 µF + 100 nF | |
| 输出滤波 | 10 µF + 2×2.2 µF | |

**官方明确的三条约束**：

- 推荐 **5V 供电**，经板载稳压得 3.3V，避免误接高压烧芯片
- 也可外部直供 3.3V，绕过稳压
- **3.3V 对外输出最大负载电流 ≤ 500 mA**（带屏带模块要注意预算）

**模拟电源**：`VDDA` 经磁珠 `CBG160808U121T` 从 3.3V 隔离，配 10 µF + 100 nF；`VREF+` 直连 VDDA。

**备份电源**：纽扣电池座 + `BAT54C`（双肖特基，电池/VDD 自动切换）→ `VBAT`。**不装电池 RTC 掉电不保持**。

**Type-C**：16 脚母座，支持正反插；`CC1/CC2` 各串 **5.1 kΩ** 下拉（UFP 规范）；`DP/DN` 直连 **PA12/PA11**（USB_OTG_FS），可做 USB 应用或 **DFU 下载**；**未做 ESD 保护器件**。

### 10.4 时钟与启动

| 时钟 | 器件 | 负载电容 | 引脚 |
|:--|:--|:--|:--|
| HSE | **8 MHz 无源晶振 3225** | 各 10 pF | PH0 / PH1 |
| LSE | **32.768 kHz** | 各 10 pF | PC14 / PC15 |

**PLL 配置（工程实测）**：

```c
PLLM = 8;              // 8 MHz / 8 = 1 MHz
PLLN = 336;            // 1 MHz × 336 = 336 MHz (VCO)
PLLP = RCC_PLLP_DIV2;  // 336 / 2 = 168 MHz → SYSCLK
PLLQ = 4;              // 84 MHz（通用工程）
PLLQ = 7;              // 48 MHz（USB 工程必须用 7）
```

总线：AHB 168 MHz，APB1 = 42 MHz（÷4），APB2 = 84 MHz（÷2）。

> **最容易踩的坑**：要用 USB 时 `PLLQ` 必须为 **7**。LED/按键例程里的 `PLLQ = 4` 拿去做 USB 会枚举失败。

**复位**：`10 kΩ` 上拉 + `100 nF` 到地 → 上电复位；轻触按键手动复位；`1 kΩ` 串在复位网络里，图纸注释"用户将电源线错接到 RST 时起限流保护作用"。

**BOOT**：BOOT0（pin 94）10 kΩ 下拉，按键按下拉高 → 进系统存储器启动（DFU）；BOOT1 / PB2（pin 37）10 kΩ 下拉，板上有跳线帽位。

> PB2 被 BOOT1 下拉占用，当普通 IO 用可以，但输出高电平时会与 10 kΩ 下拉打架（约 0.3 mA 灌电流），一般无碍。

### 10.8 上手注意点

1. **只走一路供电**：Type-C 和 +5V 排针别同时接，板上没有防倒灌设计
2. **3.3V 对外最多 500 mA**：3.5 寸屏背光就要 100 mA 以上，再挂模块容易触上限掉压
3. **USB 工程要改 `PLLQ=7`**，否则 48 MHz 出不来
4. **改了 `HSE_VALUE` 要全工程一致**：板载 8 MHz（注意老 HAL 库默认 25 MHz 的坑）
5. **FSMC 屏和 SPI 屏共用 PD12/PC2**，只能二选一
6. **PB3/PB4/PA15 是 JTAG 脚**，当 IO 用要关 JTAG，调试器设成 SWD 模式
7. **BOOT0 按键按下 = 进 DFU**：程序"不跑"先看这个键是不是卡住
8. **RDP 读保护**：二手板 ST-Link 报"找不到目标"，用 CubeProgrammer 解保护 + 全片擦除
9. **立创 EDA 封装 ≠ AD 封装**：官网 AD 包标的是 VET6-Mini 款
10. **文档里的中文参考手册值得用**：21 MB 全本，查寄存器比翻英文 RM0090 快
