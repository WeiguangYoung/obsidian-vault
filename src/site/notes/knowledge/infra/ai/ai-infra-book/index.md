## 全书主线：六层分工

```
应用与任务          ← 要完成什么任务，多快返回，成本上限（第 1、3 章）
模型与负载          ← 结构决定算什么、留什么状态（第 2、3 章）
训练与推理系统      ← 组织 batch、管理状态、调度加速器（第 8—10 章）
算子与编译运行时    ← 分块、融合、复用、并发（第 5 章）
处理器与存储        ← 算力、容量、带宽的物理约束（第 4 章）
互联与数据中心      ← 超节点、网络、供电散热（第 6、7、12 章）
```

调度与运行环境（第 11 章）横切系统层，端边云协同（第 12 章）把执行位置从数据中心扩展到设备侧。

## 贯穿全书的两个抓手

| 抓手 | 含义 |
|:--|:--|
| **量化估算五问** | 反复追问数据搬移：**搬什么、搬多少、搬几次、经过哪里、谁必须等它** |
| **极限对比法** | 按第一性原理算出硬件物理极限（下界），下界与实测之比就是利用率；差距不是模型漏了项，就是系统有可以去掉的开销 |

## 推荐阅读路径（作者建议）

- **做模型应用 / 推理服务**：重点 8、9 章，再看 11、12 章；遇到容量、算子或通信问题回到 4—7 章追踪原因
- **做系统 / 网络**：重点 5—7 章，再看 9、10 章
- **做芯片 / 体系结构**：重点 4—7 章，结合后续章节任务算例
- **系统学习**：按顺序读，先 1—3 章建立模型与负载的概念底座，配合 `calc.py` 计算工具核对数字
