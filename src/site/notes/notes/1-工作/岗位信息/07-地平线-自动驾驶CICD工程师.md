## 📋 职位详情

**岗位职责：**
1. 负责自动驾驶核心业务的 **CI/CD 研发效能体系**搭建与迭代优化，搭建适配自动驾驶**嵌入式、算法、软件融合开发**场景的自动化构建、测试、打包、部署、发布全流程流水线，支撑多版本、多分支、多车型并行研发交付；
2. 解决大型智驾项目**代码编译耗时久、依赖复杂、交叉编译冲突、多版本兼容、编译缓存失效**等核心问题，优化编译链路、提升整机软件构建效率，保障大规模代码库的稳定高效构建；
3. 负责 **DevOps 平台工具**的开发、迭代与运维，对 **GitLab CI、Jenkins、Argo Workflows** 等主流 CI/CD 工具进行**二次开发与定制化改造**，结合 **K8s 容器化架构**，搭建自动化、可观测、可管控的研发交付基础设施，适配自动驾驶软硬一体的研发交付场景；
4. 搭建**研发质量与效能监控体系**，统计构建成功率、流水线通过率、编译耗时、迭代周期、缺陷逃逸率等核心指标，沉淀自动驾驶行业 DevOps 最佳实践；
5. 负责研发环境、构建集群、测试资源的管理与调度，解决流水线运行异常、编译报错、部署失败等线上问题，保障研发流程稳定高效运转，支撑大规模团队协同；
6. 挖掘研发交付痛点，持续优化自动化脚本、构建工具、发布流程，完善**代码准入、自动化测试、版本回溯、灰度发布**机制，提升自动驾驶产品整体研发交付效率与质量。

**任职资格：**
1. 本科及以上，计算机、软件工程、电子信息、车辆工程等相关专业，**2-5 年及以上 DevOps/CI/CD 开发建设经验**，有**自动驾驶、智能汽车、嵌入式大型项目**从业经验者优先；
2. **扎实的 C++ 代码功底**，深入理解 C++ 编译链接原理、静态链接/动态链接、编译依赖管理、**交叉编译机制**，熟悉 **Make、CMake、Bazel** 等主流编译构建工具，能独立优化大型 C++ 工程编译体系，解决复杂编译问题；
3. 精通完整 CI/CD 流程：Git 版本管理、分支策略、代码评审、自动化构建、持续测试、持续部署、版本管理全链路，具备**大型复杂项目 CI/CD 体系从零搭建、迭代优化、落地运维**的完整经验；
4. 熟练使用 **Python/Shell** 等脚本语言，可独立开发自动化工具、运维脚本、流水线插件，具备主流 CI/CD 平台**二次开发**能力，熟悉容器化技术（**Docker/K8s**），了解 **Ansible、Terraform** 等基础设施自动化工具；
5. 熟悉 **Linux** 开发环境，精通系统运维、进程管理、日志分析、性能调优，具备**构建集群资源调度、故障排查、性能优化**实战经验，能快速定位并解决流水线、编译、部署全链路问题；
6. 具备自动驾驶行业大型项目 CI/CD 建设经验，了解智驾软件研发流程、嵌入式软硬件开发模式、多车型多版本迭代特性者优先，**熟悉 ROS/ROS2 架构、车载软件交付流程者加分**；
7. 代码规范意识强，逻辑思维清晰，具备良好的问题复盘能力和跨团队沟通能力，有较强的自驱力和落地能力，能独立承接大型效能优化项目。
