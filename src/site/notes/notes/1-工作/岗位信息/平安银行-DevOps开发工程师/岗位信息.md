# 🏦 平安银行 — DevOps开发工程师（岗位JD）

> 📅 2026-09-05 获取（BOSS 直聘 22:35 截图，公司名 22:40 补充确认）

---

## 岗位职责

1. 负责对研发交付流程的管理和检视，识别问题点，提供工具和流程的改进方案
2. 参与 CI/CD 流水线设计、搭建与优化，辅助提升研发交付效率与质量
3. 参与开发测试环境基础组件（容器化平台、中间件等）的自动部署与维护，上线流程的跟进
4. 参与构建并维护**可观测性体系（日志、监控、链路追踪），实现系统全链路可视化**
5. 参与研发效能工具的设计与开发，**探索并实践 AI 大模型在 DevOps 场景的应用**

## 任职要求

1. 熟悉研发交付流程和最佳实践
2. 熟悉 CI/CD 工具链的设计与调优
3. 熟练掌握 Docker、Kubernetes 等容器技术
4. 熟悉主流可观测系统的搭建和使用
5. 具备扎实的编程能力，熟练掌握至少一种主流语言（Python/Shell/Go/Java 等）

## 加分项

对 AI 大模型技术有浓厚兴趣，具备以下任一经验者优先：
- 使用 LLM 开发过研发辅助工具
- 有基于大模型的代码生成、注释补全、缺陷检测等项目实践
