# 🏦 平安银行 DevOps开发工程师 — 技术学习路线

> 按 JD 点名优先级排序，全部可在家用环境（腾讯云 Jenkins + 阿里云 k3s）做出实操作品。

## 1. 可观测性体系（JD 点名，当前最大短板，优先补）⭐

- **Prometheus**：部署（kube-prometheus-stack）、PromQL、exporter 体系、服务发现
- **Grafana**：Dashboard 搭建、变量/模板、告警规则
- **Loki + Promtail**：日志采集与 LogQL 检索（对照 ELK 了解差异，金融岗可能被问）
- **链路追踪**：Jaeger / OpenTelemetry 基础概念 + 给 demo 应用埋点跑通一条 trace
- 实操落点：k3s 双节点装 kube-prometheus-stack + Loki/Grafana；给 Jenkins 本身接 Prometheus 插件出构建指标（一举两得）
- 金融语境：全链路可视化、生产变更可观测、告警分级与 oncall

## 2. AI 大模型 × DevOps（加分项 → 主打差异化）🌟

- 已有实践：LLM Agent 接管 Jenkins 运维（盯构建/拉日志/跨节点诊断/文档沉淀），整理成可演示的作品：
  - 一篇实践文章（素材：2026-09-05 两篇实战排障文档）
  - 真实用量数据佐证（DeepSeek API：缓存命中率 92.35%、月成本）
- 理论补课：代码生成/补全/缺陷检测的工具版图（Copilot、通义灵码、CodeGeeX）、LLM 做日志异常检测的思路
- 面试叙事：效能提升量化（排障耗时对比、自动化覆盖率）

## 3. CI/CD 深水区（要求"设计与调优"，不停在"会用"）

- GitLab CI/CD 补课：起 Runner 把现有 hello-jenkins 流水线跑一遍，对比 Jenkins（插件生态 vs MR 原生/开箱即用）
- Jenkins 进阶：Shared Library（win/k8s 两线收敛）、Multibranch Pipeline、JCasC、凭证体系迁移
- 质量门禁：SonarQube / Trivy 镜像扫描串进流水线（金融行业必问安全扫描）
- 效能度量：DORA 四指标（部署频率/变更前置时间/变更失败率/MTTR），写个 Python 脚本拉 Jenkins API 算——同时补"编程"和"效能工具开发"两条

## 4. 容器平台与自动部署（职责 3：平台+中间件自动部署）

- Helm Chart 编写与发布（把 nginx-demo 或 Jenkins agent 模板 Chart 化）
- 中间件部署实操：在 k3s 上部署一套 Redis/MySQL（bitnami chart），体会"环境交付"
- IaC 意识：Terraform 管阿里云资源（VPC 对等/安全组这两天的手工活正好脚本化）、Ansible 基础

## 5. 研发交付流程与金融合规语境（职责 1）

- 交付流程检视的抓手：代码评审卡点、流水线准入准出标准、灰度/回滚预案
- 金融行业特殊性：等保/监管审计、变更窗口、生产权限最小化（和互联网裸奔玩法的差异，面试聊到加分）
- 了解平安科技/金融云技术栈风格（私有化 K8s、自研平台多，平台共建意识）

## 学习顺序建议

1~2 周：可观测性栈实操（出 Grafana 截图级作品）→ AI+DevOps 文章 → DORA 度量脚本
之后：GitLab CI 对比实践 → Helm/中间件部署 → JCasC/Shared Library 收尾 Jenkins 进阶
