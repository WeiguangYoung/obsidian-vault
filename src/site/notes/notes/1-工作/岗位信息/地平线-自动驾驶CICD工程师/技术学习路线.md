# 🚗 地平线 自动驾驶 CI/CD / DevOps 工程师 — 技术学习路线

> 目标：把已有「嵌入式 C/C++ + 交叉编译 + Jenkins 二次开发 + K8s」经验升级为**智驾级大规模构建体系**叙事，补齐 Bazel 与 ROS2。

## 1. 大型 C++ 编译体系（核心，已有强基础）
- **编译链接原理**：预处理 → 编译 → 汇编 → 链接；静态/动态链接、符号解析、重定位、ODR
- **依赖管理**：头文件依赖图、Include-What-You-Use（IWYU）、前向声明、Pimpl 惯用法
- **交叉编译**：toolchain file、sysroot、target triple、`--sysroot`/`-B`、多架构产物隔离
- **构建加速**：
  - `ccache` / `sccache` 本地/远程缓存
  - 增量构建、`ninja` 替代 make、`-j` 并行度调优
  - 分布式编译：distcc / Buildbarn / Icecream
  - 链接期优化：gold / lld、`--gc-sections`（已有 FlashDriver 实战经验）
- **构建缓存失效根因排查**：时间戳 vs 内容哈希、绝对路径污染、环境变量泄漏 → 可复现构建（reproducible build）

## 2. Bazel（缺口，重点补）
- 核心概念：WORKSPACE / MODULE.bazel、BUILD、target、label、规则（rule）
- 依赖模型：精确依赖图、沙箱执行、remote cache / remote execution（RBE）
- 与 CMake 的认知迁移：从「脚本式配置」到「声明式依赖图」
- 交付物：把一个现有 CMake 项目改造成 Bazel 构建，对比构建耗时与缓存命中率

## 3. CI/CD 平台与二次开发（已有，需体系化）
- **Jenkins 二次开发**：Shared Library（✅ 已有）、插件开发（Java）、Pipeline 性能调优、高可用（Controller/Agent 分离）
- **Argo Workflows**：DAG、Artifact、Cron、并行 fan-out/fan-in
- **GitLab CI**：多阶段 Pipeline、Runner 管理、缓存与 Artifacts
- **流水线度量**：构建成功率、通过率、编译耗时、迭代周期、缺陷逃逸率（对应 JD 第 4 条）

## 4. 多版本 / 多分支 / 多车型并行
- 分支模型：Git Flow / Trunk Based / Release+Hotfix 分支
- 版本号规范：语义化版本、构建号、内部版本追溯
- **多车型并行编译**：配置矩阵、参数化构建、产物命名隔离
- 发布流程：代码准入 → 自动化测试 → 版本回溯 → **灰度发布**

## 5. 构建集群与资源调度（已有 K8s 基础）
- K8s 动态 Agent（Jenkins k8s plugin）、Pod 模板、资源配额
- 构建集群调度：优先级、污点容忍、节点亲和（✅ 已有双污点策略实战）
- 资源隔离与成本：Build Farm 容量规划、超卖与 QoS
- 故障排查：流水线卡死、Pod Pending、镜像拉取失败

## 6. 质量与效能监控体系
- 静态检查：Cppcheck（✅ 已有 codeCheck）、Clang-Tidy、Coverity、CodeQL、SonarQube
- 测试度量：单测覆盖率（✅ 已有 coverage）、缺陷逃逸率
- 可观测性：Jenkins/Argo 指标 → Prometheus + Grafana（✅ kps 监控栈直接复用）

## 7. 脚本与基础设施自动化
- Python / Shell 自动化工具开发（已有）
- 流水线插件开发（Groovy / Java）
- Ansible（配置管理）、Terraform（基础设施即代码）

## 8. ROS / ROS2（加分项，接 8 周计划）
- ROS2 基础：节点、Topic、Service、Action、Launch、Colcon 构建
- 车载软件交付流程：OTA、版本签名、安全启动
- 详见：[ROS2 具身智能 CI 实战](../../../../knowledge/devops/ROS2具身智能CI实战.md)
