## 📋 职位详情

**职位描述：**
1. 参与设计并开发**基于大模型的代码库治理 Agent**，负责治理任务的工作流设计，使其能自主完成代码审查、优化、重构、修复等任务；
2. 参与**自动驾驶 CI/CD 平台**与研发流程的设计、开发和维护工作；
3. 参与优化现有平台框架及组件，提高平台处理效率。

**职位要求：**
1. 计算机相关专业本科及以上学历，**3-4 年软件开发经验**，具备扎实的计算机基础知识；
2. 熟练使用至少一门常用编程语言（**Python、Golang、C++ 优先**），熟悉 Linux 环境和 Shell 脚本；有良好的代码风格、开发习惯和文档规范；
3. **对 AI Agent / 大模型应用有强烈兴趣**，熟悉 Function Calling / Tool Use、RAG、MCP（Model Context Protocol）等机制；有 **LangGraph、AutoGen、OpenAI Agents SDK** 或类似 Agent 框架的落地经验；
4. 自我驱动，具备较强的学习、沟通能力，能独立负责模块并主动推动跨团队问题解决；
5. 良好的英文阅读能力，较好的听说能力。

**加分项：**
1. 具备 CI/CD、DevOps 或研发效能平台相关经验，熟悉 **Git、Jenkins、GitLab CI/GitHub Actions** 等工具；
2. 有**代码智能、自动修复、测试治理等 Agent 项目经验**，或构建过 Agent 评测集与可观测性链路；
3. 熟悉云原生技术栈，如 **Docker、Kubernetes** 等；
4. 了解 **Argo Workflows、ArgoCD** 或其他开源 CI/CD 工具；
5. 有**大型 C++ / Monorepo 代码库治理**或 **Bazel / CMake** 构建工具经验者优先。

## 🦐 虾管家点评
> 这是**「CI/CD 平台 + AI Agent」双主线**的岗位，恰好卡在本人的能力交集上：
> - 现有 Jenkins Shared Library / 质量门禁 / K8s 监控栈经验 → 直接命中加分项 1、3、4；
> - C/C++ 嵌入式构建 + CMake + 大仓改造经验 → 命中加分项 5（Monorepo / Bazel / CMake），这是稀缺项；
> - **最大缺口 = AI Agent 工程化**（LangGraph / MCP / Function Calling 落地 + Agent 评测集），需要专项补齐才能拿下第 3 条硬要求。
> 建议：把「Shared Library + 质量门禁」包装成**「代码治理 Agent 的工具体系」**来叙事，与 JD 第 1 条强对齐。
